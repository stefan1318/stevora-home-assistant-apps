# [STE-01] STEVORA Home Panel 7.1.1 — Premium UI / Universal Integration 0.2.0-rc.2

**Състояние:** тестов кандидат, без официално внедряване.
**Клон:** \`feature/stevora-home-panel-v711-premium-20261119\`
**Pull Request:** https://github.com/stefan1318/stevora-home-assistant-apps/pull/8
**Изискване:** тестова независима Home Assistant инсталация. Не обновявайте Dunav преди реална визуална и контролна проверка.

## Защо е преработен панелът

Изходната \`0.2.0-rc.1\` интеграция съдържа правилен динамичен manifest, но видимият Home Panel е минимален интерфейс. Историческият v7.1.1 съдържа премиум дизайн, но и фиксирани entity IDs от един конкретен дом; директното копиране би нарушило универсалната съвместимост.

Този кандидат възстановява визуалната система и навигационната концепция, като използва **само** текущите потребителски разрешени \`stevora/manifest\`, \`stevora/panel/generate\` и живото HA състояние.

## Premium UI

- Локални, независими от CDN CSS стилове с v7.1.1 тъмна палитра, градиентен Home екран, фирмен векторен знак, адаптивни карти и навигация.
- Десктоп странично меню; мобилно долно меню; режим за стенен панел.
- Екрани: Начало, Помещения, Климат, Осветление/RGB, Устройства, Сцени, Статистика, AI център, Система, Памет, Настройки.
- Динамични стаи и контролни карти: без фиксирани имена и идентификатори от Home Assistant Dunav.
- На Начало: информативна климатична карта, състояние, бързо осветление, стаи, сензори.
- Климат: разрешени ±1°C настройки с валидиране на HA min/max и разширени родни HA контроли.
- Осветление: разрешени ON/OFF, яркост и RGB; без подсветки.
- Настройки: наследени Room, Device, Translation, Visibility и Assistant Admin Managers, без загуба на записаните данни.
- Система: manifest revision, installation ID, modules, диагностика само за администратори.
- AI/Memory/Scenes: не се обявяват за функционално включени, ако реалните модули не са налични; native HA редакторите остават отделни.

## Инсталация

1. Направете **пълен backup** на независимия тестов Home Assistant и запазете предишната папка \`/config/custom_components/stevora\`.
2. Изтеглете **само** успешния CI Artifact \`STEVORA-Universal-Integration-0.2.0-rc.2\` от последния зелен **STEVORA integration checks** run в PR #8.
3. Разархивирайте външния GitHub artifact ZIP. Проверете \`SHA256SUMS.txt\` за вътрешния \`stevora-universal-integration-0.2.0-rc.2.zip\`.
4. Разархивирайте вътрешния ZIP върху **тестовото** \`/config/custom_components/stevora/\`, като се запази йерархията.
5. Рестартирайте HA, направете пълно презареждане на браузъра и отворете \`/stevora\`. Проверете \`/stevora_static/stevora-premium.css?v=711\` се зарежда с HTTP 200.
6. Ако UI се показва базов, направете hard-refresh и проверете, че HTML използва класа \`v7-shell\` и URL на версия \`7.1.1-rc2\`. Не инсталирайте старата \`stevora_manifest\` едновременно.

## Граници на RC

Premium UI е отделна **UI оптимизация**. Не е автоматично включване на Home Hub, отделен Hey Stevora engine, Memory Sync, AI модели или исторически Recorder графики. Не правете production merge и не обновявайте Dunav преди визуалните и интеграционните проверки.
